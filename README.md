# Supermercado - Desarrollo Frontend II

Proyecto de la semana 3 

Es una página para ver el inventario de un supermercado, agregar productos y manejar un carrito de compras.

## Qué se puede hacer

- Ver todos los artículos y sus datos.
- Filtrar por categoría y buscar por nombre.
- Abrir el detalle de un producto.
- Agregar artículos al carrito, descontando el stock disponible.
- Aumentar, disminuir o quitar productos del carrito. Al devolver unidades se actualiza el stock.
- Registrar nuevos artículos.
- Mantener los cambios al actualizar el navegador usando localStorage.

## Cómo abrirlo

Se necesita Node.js instalado.

1. Abrir la carpeta con Visual Studio Code.
2. Abrir una terminal en la carpeta.
3. Ejecutar `npm install`.
4. Ejecutar `npm run dev`.
5. Entrar a la dirección local que muestra la terminal.

Para probar la versión de producción se usa `npm run build` y luego `npm run preview`.

## Tecnologías

React, React Router, Tailwind CSS y Vite.
